## 使用Visual Studio开发

1. 打开VS（Visual Studio），选择「创建新项目」。

在IDE中，「项目」代表生成程序所需的所有资源的集合，
包括源代码、音频、数据文件、编译链接设置等。

当需要创建新程序时，需要重新创建新的项目。
不同IDE的项目有不同的保存格式，一般无法打开其他IDE创建的项目。

1. 选择控制台应用

学习C++基础知识时，建议选择「控制台应用」。

控制台应用是指生成的程序从命令行读取数据或打印数据到命令行。
不涉及复杂的图形界面操作，同时无需修改即可在不同操作系统上运行，非常适合入门学习。

1. 填写项目名称

填写项目名称「HelloWorld」。推荐选择「将解决方案和项目放在同一目录」。

单个解决方案里，可包含多个项目，这里暂时不展开。

1. 运行项目

项目打开后，右侧「资源管理器」中包含解决方案和项目。
「源文件」中有「HelloWorld.cpp」。
在中间的编辑器中可以看到「HelloWorld.cpp」的源代码。
点击「调试」-「开始执行不调试」即可运行程序。

此时，窗口下方「输出」框里会显示如下文字，代表编译成功。

## 使用命令行进行开发

首先在编辑器中输入如下代码。保存为「HelloWorld.cpp」。

```C++
#include <iostream>

int main()
{
    std::cout << "Hello World!" << std::endl;
    return 0;
}
```

```C++
#include <iostream>

{
    std::cout << "Hello World!" << std::endl;
    return 0;
}
```

    std::cout << "Hello World!" << std::endl;
