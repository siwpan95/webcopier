## 使用std::initializer_list进行类初始化

当编译器看到初始值设定项列表时，它会自动将其转换为类型为std::initializer_list的对象。

因此，如果我们创建一个接受std::initializer_list参数的构造函数，就可以使用初始化列表作为输入来创建对象。

关于std::initializer_list，有几点需要了解。

与std::array或std::vector类似，您必须使用尖括号告诉std::initializer_list列表中保存的数据类型。因此，您几乎不会看到单独使用的std::initializer_list。相反，您会看到类似于std::initializer_list<int>或std::initializer_list<std::string>的写法。

其次，std::initializer_list有一个size()函数，用于返回列表中的元素个数。当我们需要知道传入列表的长度时，这很有用。

第三，std::initializer_list通常通过值传递。与std::string_view很相似，std::initializer_list是一个视图。复制std::initializer_list不会复制其中的元素。

让我们看看IntArray类如何使用接收std::initializer_list的构造函数：

```C++
#include <algorithm> // for std::copy
#include <cassert> // for assert()
#include <initializer_list> // for std::initializer_list
#include <iostream>

class IntArray
{
private:
	int m_length {};
	int* m_data{};

public:
	IntArray() = default;

	IntArray(int length)
		: m_length{ length }
		, m_data{ new int[static_cast<std::size_t>(length)] {} }
	{

	}

	IntArray(std::initializer_list<int> list) // 允许IntArray使用初始化列表作为输入
		: IntArray(static_cast<int>(list.size())) // 使用代理构造函数进行初始化
	{
		// 现在从初始化列表中拷贝数据
		std::copy(list.begin(), list.end(), m_data);
	}

	~IntArray()
	{
		delete[] m_data;
		// 这里没有将 m_data 设为 null，m_length 设置为 0，因为对象被销毁，没有任何人可以使用
	}

	IntArray(const IntArray&) = delete; // 避免浅拷贝
	IntArray& operator=(const IntArray& list) = delete; // 避免浅拷贝

	int& operator[](int index)
	{
		assert(index >= 0 && index < m_length);
		return m_data[index];
	}

	int getLength() const { return m_length; }
};

int main()
{
	IntArray array{ 5, 4, 3, 2, 1 }; // 初始化列表
	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' ';

	return 0;
}
```

## 访问std::initializer_list中的元素

在某些情况下，您可能希望在将std::initializer_list的每个元素复制到内部数组之前先访问该元素（例如，检查值是否合法，或以某种方式修改这些值）。

由于一些难以解释的原因，std::initializer_list不支持通过下标（operator[]）访问列表元素。这个遗漏已经多次向标准委员会提出，但一直没有得到解决。

然而，有许多简单的解决方法：

1. 可以使用基于范围的for循环来迭代列表的元素。
1. 另一种方法是使用begin()成员函数获取std::initializer_list的迭代器。由于此迭代器是随机访问迭代器，因此可以对迭代器进行索引。

```C++
IntArray(std::initializer_list<int> list) // 允许IntArray使用初始化列表作为输入
	: IntArray(static_cast<int>(list.size())) // 使用代理构造函数进行初始化
{
	// 现在从列表中初始化我们的数组
	for (std::size_t count{}; count < list.size(); ++count)
	{
		m_data[count] = list.begin()[count];
	}
}
```

## 列表初始化优先匹配列表构造函数

非空初始值设定项列表始终会优先匹配initializer_list构造函数，而不是其他可能匹配的构造函数。考虑：

```C++
IntArray a1(5);   // 匹配 IntArray(int), 分配长度为 5 的数组
IntArray a2{ 5 }; // 匹配 IntArray<std::initializer_list<int>, 分配数组长度为 1
```

```C++
IntArray a1(5);   // 匹配 IntArray(int), 分配长度为 5 的数组
IntArray a2{ 5 }; // 匹配 IntArray<std::initializer_list<int>, 分配数组长度为 1
```

```C++
IntArray a1(5);   // 匹配 IntArray(int), 分配长度为 5 的数组
IntArray a2{ 5 }; // 匹配 IntArray<std::initializer_list<int>, 分配数组长度为 1
```

a1使用直接初始化（不匹配列表构造函数），因此该定义将调用IntArray(int)，分配大小为5的数组。

如果使用列表初始化进行委托，构造函数将尝试委托给自己，这将导致编译错误。

同样的情况也会发生在std::vector和其他容器类上，这些容器类同时具有列表构造函数，以及参数类型相近的其它构造函数。

```C++
std::vector<int> array(5); // 调用 std::vector::vector(std::vector::size_type), 5 个值初始化的元素: 0 0 0 0 0
std::vector<int> array{ 5 }; // 调用 std::vector::vector(std::initializer_list<int>), 1 个元素: 5
```

## 使用std::initializer_list进行类赋值

您还可以通过重载赋值运算符，使用std::initializer_list参数为类分配新值。这与上面的机制类似。下面进行演示。

请注意，如果实现了接收std::initializer_list的构造函数，则应确保至少执行以下操作之一：

1. 提供重载的列表赋值运算符
1. 提供适当的深拷贝语义的拷贝赋值运算符
1. 删除拷贝赋值运算符

原因如下：考虑以下类（它没有上面提到的三点逻辑），以及列表赋值语句：

```C++

#include <cassert>   // for assert()
#include <initializer_list> // for std::initializer_list
#include <iostream>

class IntArray
{
private:
	int m_length{};
	int* m_data{};

public:
	IntArray() = default;

	IntArray(int length)
		: m_length{ length }
		, m_data{ new int[static_cast<std::size_t>(length)] {} }
	{

	}

	IntArray(std::initializer_list<int> list) // 允许IntArray使用列表初始化
		: IntArray(static_cast<int>(list.size())) // 使用代理构造函数进行初始化
	{
		// 现在从列表中初始化我们的数组
		std::copy(list.begin(), list.end(), m_data);
	}

	~IntArray()
	{
		delete[] m_data;
	}

//	IntArray(const IntArray&) = delete; // 避免浅拷贝
//	IntArray& operator=(const IntArray& list) = delete; // 避免浅拷贝

	int& operator[](int index)
	{
		assert(index >= 0 && index < m_length);
		return m_data[index];
	}

	int getLength() const { return m_length; }
};

int main()
```

首先，编译器会注意到接收std::initializer_list的赋值函数不存在。接下来，它会查找其它可用的赋值函数，并发现隐式提供的拷贝赋值运算符。然而，只有当它可以将初始值设定项列表转换为IntArray时，才能使用此函数。由于{1,3,5,7,9,11}是std::initializer_list，编译器会使用列表构造函数将该初始值设定项列表转换为临时IntArray。然后，它会调用隐式赋值操作符，将临时IntArray浅拷贝到array对象中。

此时，临时IntArray的m_data和array->m_data都指向同一个地址（由于浅拷贝）。

在赋值语句结束时，临时IntArray会被销毁。它会调用析构函数，而析构函数会删除临时IntArray的m_data。这会使array->m_data成为悬空指针。当您尝试以任何方式使用array->m_data时（包括在析构函数中删除m_data），都会产生未定义行为。

> **提示:** 最佳实践如果提供了列表构造函数，最好也提供列表赋值函数。
