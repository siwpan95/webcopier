在上一课中，我们提到枚举元素是符号常量。还没有说明的是，枚举元素是整型符号常量。因此，枚举类型实际上保存的是整数值。

这类似于使用char的情况。考虑：

```C++
char ch { 'A' };
```

char本质上只是一个1字节的整数值，字符’A’会被转换为整数值（在本例中为65）并存储。

定义枚举时，每个枚举元素都会根据其在枚举列表中的位置自动分配一个整数值。默认情况下，为第一个枚举元素分配整数值0，并且每个后续枚举元素的值都比前一个大一：

```C++
enum Color
{
    black, // 值为 0
    red, // 1
    blue, // 2
    green, // 3
    white, // 4
    cyan, // 5
    yellow, // 6
    magenta, // 7
};

int main()
{
    Color shirt{ blue }; // shirt 实际存储了整数值 2

    return 0;
}
```

可以显式定义枚举元素的值。这些整数值可以是正值或负值，并且可以与其他枚举元素共享相同的值。任何未定义的枚举元素都被赋予比前一个大一的值。

```C++
enum Animal
{
    cat = -3,
    dog,         // 值为 -2
    pig,         // -1
    horse = 5,
    giraffe = 5, // 与 horse 存储相同的值
    chicken,      // 6 
};
```

注意，在这种情况下，horse和giraffe被赋予了相同的值。发生这种情况时，枚举元素会变得无法区分——本质上，horse和giraffe在使用时可以互换。尽管C++允许这样做，但通常应避免将相同的值分配给同一枚举中的两个枚举元素。

> **提示:** 最佳实践避免将显式值分配给枚举元素，除非有令人信服的理由这样做。

在函数调用中或与运算符一起使用枚举类型时，编译器会首先尝试查找与枚举类型匹配的函数或运算符。例如，当编译器尝试编译 std::cout « shirt 时，会先查看 运算符« 是否知道如何将Color类型的对象（因为shirt的类型是Color）打印到std::cout。这里找不到匹配项。

如果编译器找不到匹配项，则编译器将隐式地将枚举元素转换为其相应的整数值。因为std::cout可以打印整数值，所以shirt中的值被转换为整数并打印为整数值2。

## 打印枚举元素名称

在大多数情况下，将枚举打印为整数值（如2）并不是我们想要的。相反，通常希望打印枚举元素表示的名称（blue）。但要做到这一点，需要某种方法将枚举的整数值（2）转换为与枚举元素名称（“blue”）匹配的字符串。

截至C++20，C++没有简单的内置方式来实现这一点，因此必须自己实现解决方案。幸运的是，这并不困难。典型方法是编写一个函数，将枚举类型作为参数，然后输出相应的字符串（或将字符串返回给调用方）。

```C++
// 这里使用if else，运行效率不高

{

    else if (color == red) std::cout << "red";
    else if (color == blue) std::cout << "blue";
    else std::cout << "???";
}
```

## 设定运算符«以打印枚举数

尽管上面的示例运行良好，但我们仍然必须记住创建的函数名称，才能获得枚举元素名称。虽然这通常不算繁琐，但如果有许多枚举，就可能变得麻烦。使用运算符重载（类似于函数重载的功能），实际上可以设定运算符«如何打印程序定义的枚举！我们还没有解释这是如何工作的，所以现在它看起来有点神奇：

```C++
#include <iostream>

enum Color
{
	black,
	red,
	blue,
};

// 设定 operator<< 如何打印 Color
// 现在可能看起来有点神奇，后续进行介绍
// std::ostream 是 std::cout 的类型
// 返回值与参数都是引用 (避免制作副本)!
std::ostream& operator<<(std::ostream& out, Color color)
{
	switch (color)
	{
	case black: return out << "black";
	case red:   return out << "red";
	case blue:  return out << "blue";
	default:    return out << "???";
	}
}

int main()
{
	Color shirt{ blue };
	std::cout << "Your shirt is " << shirt << '\n'; // it works!

	return 0;
}
```

## 枚举大小和底层类型

枚举元素是整型常量。用于表示枚举元素的具体整型类型称为其底层类型。

对于非限定作用域枚举，C++标准没有指定应将哪个特定的整型用作底层类型。大多数编译器将使用类型int作为底层类型（这意味着非限定作用域枚举将与int大小相同），除非需要更大的类型来存储枚举元素值。

可以指定不同的底层类型。例如，如果您在某些对带宽敏感的环境中工作（例如通过网络发送数据），可能需要指定较小的类型：

```C++
#include <cstdint>  // for std::int8_t
#include <iostream>

// 使用 8-bit 整数作为 Color 的底层类型
enum Color : std::int8_t
{
    black,
    red,
    blue,
};

int main()
{
    Color c{ black };
    std::cout << sizeof(c) << '\n'; // 打印 1 (字节)

    return 0;
}
```

## 整数到非限定作用域枚举转换

虽然编译器会隐式地将非限定作用域枚举转换为整数，但它不会隐式地把整数转换为非限定作用域枚举。以下操作会产生编译器错误：

```C++
enum Pet // 未指定底层类型
{
    cat, // 0
    dog, // 1
    pig, // 2
    whale, // 3
};

int main()
{
    Pet pet { 2 }; // 编译错误: 整数 2 不能隐式的转换为 Pet
    pet = 3;       // 编译错误: 整数 3 不能隐式的转换为 Pet

    return 0;
}
```

```C++
    dog, // 1
    pig, // 2
    whale, // 3
};

{
```
```C++
    std::cout << "Enter a pet (0=cat, 1=dog, 2=pig, 3=whale): ";

    int input{};
    std::cin >> input; // 输入整数

    Pet pet{ static_cast<Pet>(input) }; // static_cast 将整数转换为Pet

    return 0;
}
```
