> 来源: C++学习网 (studycpp.cn)

在许多情况下，需要多个变量来表示我们关心的事物。就像分数有分子和分母，它们共同组成数学中的一个完整概念。

又或者，假设编写一个程序，用来存储公司员工的信息。需要记录员工的姓名、职务、年龄、员工id、经理id、工资、生日、雇佣日期等属性…

然而，这种方法存在许多问题。首先，无法立即看出这些变量是否真的相关（必须阅读注释，或者查看它们在代码中的使用方式）。其次，现在有12个变量需要管理。如果想将这个员工信息传递给函数，必须传递12个参数（并且顺序要正确），这会让函数定义和函数调用变得一团糟。如果函数只能返回单个值，那么函数又该如何返回员工信息呢？

如果想要表示多个员工，就需要为每个额外的员工再定义12个变量（每个变量都需要一个唯一的名称）！这显然无法扩展。真正需要的是某种方法，将所有这些相关的数据片段组织在一起，使它们更易于管理。

幸运的是，C++提供了两种旨在解决此类问题的复合类型：结构体（struct，本课开始介绍）和类（class，稍后会探索）。结构体是程序定义的数据类型，它允许将多个变量绑定到一个类型中。这让相关变量集的管理简单得多！

## 定义结构体

由于结构体是程序定义类型，因此在开始使用之前，必须先告诉编译器这个结构体类型的定义。下面是简化后的员工结构体定义示例：

```C++
struct Employee
{
    int id {};
    int age {};
    double wage {};
};
```

```C++
struct Employee
{
    int id {};
    int age {};
    double wage {};
};
```

```C++

{
    int id {};
    int age {};
    double wage {};
};
```

| 123456 | structEmployee{intid{};intage{};doublewage{};}; |
| --- | --- |

struct关键字用于告诉编译器正在定义一个结构体，我们将其命名为Employee（因为程序定义的类型通常以大写字母开头）。

然后，在一对花括号内，定义每个Employee对象将包含的变量。在这个例子中，Employee有3个变量：int id、int age和double wage。作为结构体一部分的变量称为数据成员（或成员变量）。

就像使用一组空花括号初始化普通变量一样，每个成员变量后面的空花括号会确保创建Employee时，其中的成员变量被初始化。后续会详细介绍这一点。

最后，用分号结束类型定义。

提醒一下，Employee只是一个类型定义——此时实际上没有创建任何对象。

> **提示:** 提示在日常语言中，成员是属于一个群体的个人。例如，您可能是篮球队的成员，而您的妹妹可能是合唱团的成员。在C++中，成员是属于结构体（或类）的变量、函数或类型。所有成员都必须在结构体（或类）定义中声明。在以后的课程中，将经常使用“成员”一词，因此请确保您记住它的含义。

在上面的示例中，名称joe指的是整个结构体对象（其中包含成员变量）。要访问特定成员变量，需要在结构体变量名和成员变量名之间使用成员选择操作符（operator.）。例如，要访问joe的age成员，使用joe.age。

结构体成员变量就像普通变量一样，因此可以对它们进行普通操作，包括赋值、算术、比较等…

```C++
#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};

    joe.age = 32;  // 使用成员选择操作符 (.) 去选择 joe 的成员变量 age

    std::cout << joe.age << '\n'; // 打印 joe 的 age

    return 0;
}
```

结构体的最大优势之一是，只需要为每个结构体对象创建一个名称（成员变量名称作为结构体类型定义的一部分是固定的）。在下面的示例中，实例化了两个Employee对象：joe和frank。

```C++
#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};
    joe.id = 14;
    joe.age = 32;
    joe.wage = 60000.0;

    Employee frank {};
    frank.id = 15;
    frank.age = 28;
    frank.wage = 45000.0;

    int totalAge { joe.age + frank.age };

    if (joe.wage > frank.wage)
        std::cout << "Joe makes more than Frank\n";
    else if (joe.wage < frank.wage)
        std::cout << "Joe makes less than Frank\n";
    else
        std::cout << "Joe and Frank make the same amount\n";

    // Frank 升职加薪了
    frank.wage += 5000.0;

    // 今天是joe的生日
    ++joe.age; // Joe 的年龄加一

    return 0;
}
```
