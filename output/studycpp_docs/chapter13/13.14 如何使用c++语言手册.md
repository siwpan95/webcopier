## std::string::length

我们之前已经了解过std::string::length，该函数返回字符串的长度。

在cppreference首页，点击字符串库，查看字符串相关的文档。

这里可以看到，字符串库会根据字符串中存储的字符类型提供多个对应类型。std::string其实是std::basic_string<char>的别名。<char>表示字符串里的每个字符都是char类型；当想在字符串里存储Unicode而不是ASCII字符时，其他类型可能会更合适。

点击std::string，可以查看对应的手册。在下面，对应的小节里，可以看到，有一个length成员函数，返回字符串中的字符数。

点击进去，可以看到length函数对应的功能介绍、参数、返回值以及使用样例。

因为std::string::length是一个简单的函数，所以该页面上没有太多内容。

学习C++时，示例中会出现一些您以前没有见过的功能。可以点击对应的链接跳转过去学习。

## std::cin.ignore

在前面，我们学习了std::cin.ignore，它用于忽略直到换行符的所有内容。该函数的参数之一是一些冗长的值。那又是什么？让我们弄清楚！

首先，cin是流式输入，因此，我们点击“基于流的输入/输出”。

这里回到了我们最初的问题。可以看到，std::numeric_limits<std::streamsize>::max()对std::cin.ignore具有特殊意义，它会禁用字符计数检查。这意味着std::cin.ignore将继续忽略字符，直到找到分隔符，或者直到没有更多可查看的字符。

## 语言语法示例

除了标准库之外，cppreference还记录了语言语法。下面是一个示例程序：

```C++
#include <iostream>

int getUserInput()
{
  int i{};
  std::cin >> i;
  return i;
}

int main()
{
  std::cout << "How many bananas did you eat today? \n";

  if (int iBananasEaten{ getUserInput() }; iBananasEaten <= 2)
  {
    std::cout << "Yummy\n";
  }
  else
  {
    std::cout << iBananasEaten << " is a lot!\n";
  }

  return 0;  
}
```

## 关于cppreference准确性的警告

Cppreference不是官方文档——它是一个wiki。作为Wiki，任何人都可以添加和修改内容，内容来自社区。尽管这意味着有人可能添加错误信息，但错误信息通常会很快被发现并删除，使cppreference成为相当可靠的来源。

C++的唯一官方来源是官方标准（ [https://isocpp.org/std/the-standard](https://isocpp.org/std/the-standard) ），这是正式文档，但不太适合作为日常参考。
