# std::vector和栈行为

> 来源: C++学习网 (studycpp.cn)

---

考虑这样的情况：您正在编写一个程序，用户会输入一系列值（例如一组测试分数）。在这种情况下，用户要输入的值的数量在编译时未知，并且每次运行程序时都可能变化。您会将这些值存储在std::vector中，以供显示和/或处理。

根据到目前为止讨论的内容，可以通过以下几种方式实现这一点：

首先，您可以询问用户他们有多少个条目，创建一个具有该长度的vector，然后要求用户输入该数量的值。

这是一种不错的方法，但它要求用户提前准确知道有多少条目，并且计数时不能出错。手动计数10个或20个以上的项可能很乏味。既然程序应该替用户计算值，为什么还要让用户计算输入值的数量？

或者，我们可以假设用户不会输入超过某个数量的值（例如30），并创建（或调整）一个具有这么多元素的vector。然后要求用户输入数据，直到完成（或直到达到30个输入值）。因为vector的长度表示正在使用的元素数量，所以可以将vector调整为用户实际输入的值数量。

这种方法的缺点是用户只能输入30个值，而我们不知道这个数量是太多还是太少。如果用户想输入更多值，就会很麻烦。

可以通过添加一些逻辑来解决这个问题：每当用户达到最大值数量时，就将vector调整得更大。但这意味着必须把数组大小管理与程序逻辑混在一起，这会显著增加程序复杂性，并不可避免地提高出错概率。

这里真正的问题是，我们试图猜测用户会输入多少元素，以便适当地管理vector大小。对于输入元素数量确实事先未知的情况，有一种更好的方法。

但在此之前，我们先讨论一下什么是栈。

---

## 什么是栈（stack）？

来做个类比！考虑一下自助餐厅中的一摞盘子。由于某种未知原因，这些盘子非常重，一次只能举起一个。由于盘子是叠在一起的，因此只能通过以下两种方式操作：

1. 将一个新盘子放在最上面
1. 从最上面取出一个现有的盘子（假如存在的话）

不允许在栈的中间或底部添加或移除盘子，因为这需要一次操作多个盘子。

事物添加到栈和从栈中删除的顺序可以描述为后进先出（LIFO，last-in, first-out）。添加到栈上的最后一个元素会最先被移除。

## 编程中的栈

在编程中，栈是一种容器数据类型，其中元素的插入和删除以后进先出的方式进行。这通常通过名为push和pop的两个操作实现：

| 操作 | 行为 | 注 |
| --- | --- | --- |
| Push | 将新元素放入栈顶 |  |
| Pop | 移除栈顶元素 | 可能返回被移除元素，也可能返回void |

许多栈实现也支持其他有用操作：

| 操作 | 行为 | 注 |
| --- | --- | --- |
| Top | 获取栈顶元素 | 并不移除元素 |
| Empty | 查看栈是否是空的 |  |
| Size | 获取栈中元素的个数 |  |

栈在编程中很常见。前面讲到“使用集成调试器中的调用栈”时，我们讨论过调用栈，它用于跟踪已调用的函数。调用栈就是一种栈！调用函数时，会将包含该函数信息的条目添加到调用栈顶部。函数返回时，包含该函数信息的条目会从调用栈顶部删除。通过这种方式，调用栈顶部始终表示当前正在执行的函数，而其中的每个条目都表示之前执行到一半的函数。

## C++中的栈

在某些语言中，栈被实现为单独的容器。然而，这样的功能可能非常有限。考虑这样一种情况：希望在不修改栈的情况下打印栈中的所有值。纯栈接口并不提供执行此操作的直接方法。

在C++中，类似栈的操作被添加到现有标准库容器类中（作为成员函数）。这些容器类支持在一端高效地插入和删除元素（std::vector、std::deque和std::list）。这允许我们在保留其原本功能的同时，将这些容器中的任何一个用作栈。

在本课的其余部分中，我们将讨论std::vector的栈接口如何工作，然后讨论它如何帮助我们解决本课开头介绍的挑战。

## 使用std::vector的栈行为

std::vector中的栈行为通过以下成员函数实现：

| 函数名 | 栈操作 | 行为 | 注 |
| --- | --- | --- | --- |
| push_back() | Push | 新元素放到栈顶 | 将新元素放到vector尾部 |
| pop_back() | Pop | 移除栈顶元素 | 返回void，将vector最后一个元素移除 |
| back() | Top | 获取栈顶元素 | 不移除元素 |
| emplace_back() | Push | 更高效的push_back | 将新元素放到vector尾部 |

下面看一个使用其中一些函数的示例：

```C++
#include <iostream>
#include <vector>

void printStack(const std::vector<int>& stack)
{
	if (stack.empty()) // if stack.size == 0
		std::cout << "Empty";

	for (auto element : stack)
		std::cout << element << ' ';

	// \t 是tab, 帮助对齐
	std::cout << "\tCapacity: " << stack.capacity() << "  Length " << stack.size() << "\n";
}

int main()
{
	std::vector<int> stack{}; // 空 stack

	printStack(stack);

	stack.push_back(1); // push_back() 将一个元素推入栈中
	printStack(stack);

	stack.push_back(2);
	printStack(stack);

	stack.push_back(3);
	printStack(stack);

	std::cout << "Top: " << stack.back() << '\n'; // back() 返回最后一个元素

	stack.pop_back(); // pop_back() 移除栈最后一个元素
	printStack(stack);

	stack.pop_back();
	printStack(stack);

	stack.pop_back();
	printStack(stack);

	return 0;
}
```

## push产生的额外容量

在上面的输出中，请注意，当三个重新分配中的最后一次发生时，容量从2跳到4（尽管我们只推入了一个元素）。当推送触发重新分配时，std::vector通常会分配一些额外容量，以便继续添加其他元素，而不会在下一次添加元素时立刻触发另一次重新分配。

分配的额外容量取决于编译器对std::vector的实现，不同编译器通常会采取不同策略：

1. GCC和Clang会让当前容量加倍。触发最后一次调整大小时，容量会从2增加到4。
1. Visual Studio 2022会将当前容量乘以1.5。触发最后一次调整大小时，容量从2变为3。

因此，根据使用的编译器不同，前面的程序可能会产生略有不同的输出。

这不对：不知为何，栈开头出现了一堆0值！这里的问题是，括号初始化（设置vector的初始大小）和resize()函数都会同时设置容量和长度。我们的vector从容量3开始（这是想要的），但长度也被设置为3。因此，vector一开始就包含3个值为0的元素。后续推入的元素会被推到这些初始元素之后。

真正想要的是在不改变长度的情况下改变容量（避免未来重新分配）。

## reserve()成员函数更改容量（但不更改长度）

reserve()成员函数可用于重新分配std::vector，而不更改当前长度。

下面是与前面相同的示例，但添加了对reserve()的调用来设置容量：

```C++
#include <iostream>
#include <vector>

void printStack(const std::vector<int>& stack)
{
	if (stack.empty()) // if stack.size == 0
		std::cout << "Empty";

	for (auto element : stack)
		std::cout << element << ' ';

	// \t 是tab, 帮助对齐
	std::cout << "\tCapacity: " << stack.capacity() << "  Length " << stack.size() << "\n";
}

int main()
{
	std::vector<int> stack{};

	printStack(stack);

	stack.reserve(6); // 预设容量为6，但长度为0
	printStack(stack);

	stack.push_back(1);
	printStack(stack);

	stack.push_back(2);
	printStack(stack);

	stack.push_back(3);
	printStack(stack);

	std::cout << "Top: " << stack.back() << '\n';

	stack.pop_back();
	printStack(stack);

	stack.pop_back();
	printStack(stack);

	stack.pop_back();
	printStack(stack);

	return 0;
}
```

## push_back vs emplace_back

push_back()和emplace_back()都会将元素推送到栈上。如果要推送的对象已经存在，则push_back()和emplace_back()是等效的，应首选push_back()。

然而，在创建临时对象（与vector的元素类型相同）并将其推送到vector上的情况下，emplace_back()可能更高效：

```C++
#include <iostream>
#include <string>
#include <string_view>
#include <vector>

class Foo
{
private:
    std::string m_a{};
    int m_b{};

public:
    Foo(std::string_view a, int b)
        : m_a { a }, m_b { b }
        {}

    explicit Foo(int b)
        : m_a {}, m_b { b }
        {};
};

int main()
{
	std::vector<Foo> stack{};

	// 已经有一个对象时, push_back 和 emplace_back 基本等效
	Foo f{ "a", 2 };
	stack.push_back(f);    // 优先使用这个
	stack.emplace_back(f);

	// 当需要push一个临时对象时, emplace_back 更高效
	stack.push_back({ "a", 2 }); // 创建临时对象, 然后拷贝到vector中
	stack.emplace_back("a", 2);  // 传递参数，让对象直接在vector中创建（省略了对象拷贝）

	// push_back 不能使用显式构造函数, emplace_back 可以
	stack.push_back({ 2 }); // 编译失败: Foo(int) is explicit
	stack.emplace_back(2);  // ok
    
	return 0;
}
```

在上面的例子中，我们有一个Foo对象的vector。使用push_back({“a”, 2})时，会创建并初始化一个临时Foo对象，然后将其复制到vector中。对于复制成本高昂的类型（如std::string），这次复制可能导致性能下降。

使用emplace_back()时，不需要创建要传递的临时对象。相反，我们传递将用于创建对象的参数，并将它们转发（使用称为完美转发的功能）到vector中，在那里直接创建和初始化vector内的对象。这避免了原本需要制作的副本。

需要注意的是，push_back()不会使用显式构造函数，而emplace_back()会。这使得emplace_back更加危险，因为很容易意外调用显式构造函数，执行一些没有意义的转换。

在C++20之前，emplace_back()不适用于聚合初始化。

> **提示:** 最佳实践在创建要添加到容器的新临时对象时，或者在需要访问显式构造函数时，首选emplace_back()。否则，首选push_back()。

## 使用栈操作解决我们的挑战

现在应该很清楚，我们该如何应对本课开头介绍的挑战。如果事先不知道会向std::vector添加多少元素，使用栈函数插入这些元素就是一种方法。

下面是一个示例：

```C++
#include <iostream>
#include <limits>
#include <vector>

int main()
{
	std::vector<int> scoreList{};

	while (true)
	{
		std::cout << "Enter a score (or -1 to finish): ";
		int x{};
		std::cin >> x;

		if (!std::cin) // 处理异常输入
		{
			std::cin.clear();
			std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
			continue;
		}

		// 如果完成，跳出循环
		if (x == -1)
			break;

		// 输入有效值, 将其放入vector中
		scoreList.push_back(x);
	}

	std::cout << "Your list of scores: \n";

	for (const auto& score : scoreList)
		std::cout << score << ' ';

	return 0;
}
```
