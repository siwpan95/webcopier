# 数组、循环和有符号下标

> 来源: C++学习网 (studycpp.cn)

---

我们通常更喜欢使用有符号值来保存数量，因为无符号值的行为有时令人意外。然而，std::vector（和其他容器类）使用无符号整数类型std::size_t作为长度和索引。

这可能会导致如下问题：

```C++
#include <iostream>
#include <vector>

template <typename T>
void printReverse(const std::vector<T>& arr)
{
    for (std::size_t index{ arr.size() - 1 }; index >= 0; --index) // index 是无符号整数
    {
        std::cout << arr[index] << ' ';
    }

    std::cout << '\n';
}

int main()
{
    std::vector arr{ 4, 6, 7, 3, 8, 2, 1, 9 };

    printReverse(arr);

    return 0;
}
```

然后会表现出未定义行为。它可能会打印垃圾值，也可能使应用程序崩溃。

这里有两个问题。首先，只要index>=0，循环就会执行；而当index为无符号类型时，这个条件总是成立。因此，循环永远不会终止。

第二，当index的值为0时，继续递减index会让它回绕到一个很大的正值，然后下一次迭代会使用该值来索引数组。这是越界索引，会导致未定义行为。如果vector为空，也会遇到相同问题。

虽然有许多方法可以解决这些特定问题，但这类问题非常容易引发错误。

对循环变量使用有符号类型更容易避免此类问题，但也有自己的挑战。下面是使用有符号索引改写上述问题的一个版本：

```C++
#include <vector>

{
    for (int index{ static_cast<int>(arr.size()) - 1}; index >= 0; --index) // index 是有符号整数
    {
        std::cout << arr[static_cast<std::size_t>(index)] << ' ';
    }

    std::cout << '\n';
}

int main()
{
    std::vector arr{ 4, 6, 7, 3, 8, 2, 1, 9 };

    printReverse(arr);

    return 0;
}
```

那该怎么办呢？这是一个没有理想解决方案的领域。

这里有许多可行选择，我们将按从最差到最好的顺序介绍。您可能会在其他人编写的代码中遇到所有这些做法。

> **提示:** 注尽管我们将在std::vector的上下文中讨论这一点，但所有标准库容器（例如std::array）的工作方式都类似，并且具有相同挑战。下面的讨论适用于它们中的任何一种。

---

## 关闭有符号/无符号转换警告

如果您想知道为什么有符号/无符号转换警告通常默认禁用，那么本主题就是关键原因之一。每次使用有符号数字作为标准库容器下标时，都会生成符号转换警告。这很快会用无关警告填满编译日志，淹没真正可能有价值的警告。

因此，避免处理大量有符号/无符号转换警告的一种方法是关闭这些警告。

这是最简单的解决方案，但我们不建议这样做，因为这也会抑制真正有意义的符号转换警告，可能导致错误。

---

## 使用无符号循环变量

许多开发人员认为，由于标准库数组类型被设计为使用无符号索引，因此我们也应该使用无符号数字！这是一个完全合理的立场。只是需要格外小心，以免遇到有符号/无符号不匹配。如果可能，请避免将索引循环变量用于索引之外的任何操作。

如果决定使用这种方法，实际应该使用哪种无符号类型？

我们注意到标准库容器类定义了嵌套的typedef size_type，这是用于数组长度和索引的无符号整数类型。size()成员函数返回size_type，操作符[]使用size_type作为索引，因此从技术上讲，使用size_type作为索引类型是最一致、最安全的无符号选择（因为它在所有情况下都可以工作）。例如：

```C++
#include <iostream>
#include <vector>

int main()
{
	std::vector arr { 1, 2, 3, 4, 5 };

	for (std::vector<int>::size_type index { 0 }; index < arr.size(); ++index)
		std::cout << arr[index] << ' ';

	return 0;
}
```

## 使用有符号循环变量

尽管这会让标准库容器类型用起来稍微麻烦一些，但使用有符号循环变量与我们在代码其他部分采用的最佳实践是一致的。而且，越能坚持应用最佳实践，总体错误就会越少。

如果要使用有符号循环变量，则需要解决三个问题：

1. 应该使用什么类型？
1. 获取数组的长度作为有符号值
1. 将有符号循环变量转换为无符号索引

---

## 应该使用什么类型？

这里有三种（有时是四种）好的选择。

1. 除非数组非常大，否则 int 就足够了（通常有4个字节）。如果不关心细节，int就是默认的有符号整数。没有什么理由不用int。
1. 如果数组非常大，建议使用 std::ptrdiff_t，它通常作为 std::size_t 的有符号对应类型。
1. std::ptrdiff_t 是一个比较奇怪的名称，通常建议使用它的别名。

```C++
using Index = std::ptrdiff_t;

// 使用Index的简单示例
for (Index index{ 0 }; index < static_cast<Index>(arr.size()); ++index)
```

## 获取数组的长度作为有符号值

在C++20之前，最好的办法是将返回的长度转换为有符号整数：


这样，arr.size()返回的无符号值会被转换为有符号类型，因此比较运算符会比较两个有符号操作数。由于有符号索引变为负数时不会发生无符号回绕，因此不存在使用无符号索引时遇到的环绕问题。

这种方法的缺点是会让循环变得混乱，更难阅读。可以通过将长度移出循环来缓解这一问题：

```C++
#include <iostream>
#include <vector>

using Index = std::ptrdiff_t;

int main()
{
```

## 将有符号循环变量转换为无符号索引

一旦有了有符号循环变量，每当试图将该有符号循环变量用作索引时，就会遇到隐式符号转换警告。因此，只要打算将其用作索引，就需要某种方法把有符号循环变量转换为无符号值。

```C++
#include <iostream>
#include <type_traits> // for std::is_integral and std::is_enum
#include <vector>

using Index = std::ptrdiff_t;

template <typename T>
constexpr std::size_t toUZ(T value)
{
    // 确保 T 是整数类型
    static_assert(std::is_integral<T>() || std::is_enum<T>());
    
    return static_cast<std::size_t>(value);
}

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };

    auto length { static_cast<Index>(arr.size()) };  // in C++20, 推荐 std::ssize()
    for (auto index{ length-1 }; index >= 0; --index)
        std::cout << arr[toUZ(index)] << ' '; // 使用 toUZ() 来避免符号转换告警

    return 0;
}
```

在上面的示例中，创建了一个名为toUZ()的函数，该函数用于将整数值转换为std::size_t类型的值。“arr[ toUZ(index) ]“的可读性较好。

在前面的课程中，我们讨论过std::string拥有字符串，而std::string_view是存在于其他地方的字符串视图。std::string_view的一个妙处是，它可以查看不同类型的字符串（C样式字符串字面值、std::string和其他std::string_view），同时为我们提供一致的接口。

虽然不能修改标准库容器来接受有符号整数索引，但可以创建自己的自定义视图类来“查看”标准库容器类。在这个过程中，可以定义自己的接口，让它按我们希望的方式工作。

在下面的示例中，定义了一个自定义视图类，它可以查看任何支持索引的标准库容器。我们的接口会做两件事：

1. 允许我们使用带符号整数类型的运算符[]访问元素。
1. 以有符号整数类型获取容器长度（因为std::ssize()仅在C++20中可用）。

这里使用了操作符重载来实现操作符[]，这是尚未讨论的主题。您不需要知道SignedArrayView是如何实现的，也可以使用它。

SignedArrayView.h:

```C++
#ifndef SIGNED_ARRAY_VIEW_H
#define SIGNED_ARRAY_VIEW_H

#include <cstddef> // for std::size_t and std::ptrdiff_t

// SignedArrayView 提供了支持索引的容器类的一个视图
// 允许我们使用有符号整型
template <typename T>
class SignedArrayView // C++17
{
private:
    T& m_array;

public:
    using Index = std::ptrdiff_t;

    SignedArrayView(T& array)
        : m_array{ array } {}

    // 重载 operator[] 以使用有符号整型
    constexpr auto& operator[](Index index) { return m_array[static_cast<typename T::size_type>(index)]; }
    constexpr const auto& operator[](Index index) const { return m_array[static_cast<typename T::size_type>(index)]; }
    constexpr auto ssize() const { return static_cast<Index>(m_array.size()); }
};

#endif
```

## 唯一明智的选择：完全避免索引！

上面介绍的所有选项都有自己的缺点，因此很难明确推荐某一种方法。然而，有一种选择比其他选择明智得多：完全避免使用整数值进行索引。

C++提供了其他几种遍历数组的方法，完全不需要使用索引。如果不使用索引，就不会遇到这些有符号/无符号转换问题。

用于无索引数组遍历的两种常见方法包括range for和迭代器。

> **提示:** 相关内容下一课将讨论 range for。迭代器则会在后续专门的一章中介绍。

> **提示:** 最佳实践尽可能避免使用整数值进行数组索引。
