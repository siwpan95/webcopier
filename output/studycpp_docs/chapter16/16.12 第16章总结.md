## 章节回顾

容器是一种数据类型，为未命名对象（称为元素）的集合提供存储。当需要处理一组相关的值时，我们通常使用容器。

容器中元素的数量通常称为它的长度（有时称为大小）。在C++中，术语“大小”也常用于表示容器中的元素数。在大多数编程语言（包括C++）中，容器是同质的，这意味着容器的元素需要具有相同类型。

容器库是C++标准库的一部分，它包含实现一些常见容器类型的各种类类型。实现容器的类类型有时称为容器类。

数组是连续存储值序列的容器数据类型（意味着每个元素都放在相邻的内存位置，没有间隙）。数组允许快速、直接访问任何元素。

C++包含三种主要的数组类型：（C样式）数组、std::vector容器类和std::array容器类。

vector是C++标准容器库中实现数组的容器类之一。std::vector在<vector>头文件中定义为类模板，具有用于定义元素类型的模板类型参数。因此，std::vector<int>声明了一个元素类型为int的std::vector。

容器通常具有一个名为列表构造函数的特殊构造函数，它允许我们使用初始值设定项列表构造容器实例（列表初始化）。

在C++中，访问数组元素最常见的方法是使用数组名称和下标运算符（运算符[]）。为了选择特定元素，需要在下标运算符的方括号内提供一个整数值，用于标识要选择的元素。该整数值称为下标（非正式地称为索引）。第一个元素使用索引0访问，第二个元素使用索引1访问，以此类推。因为索引从0开始，而不是从1开始，所以我们说C++中的数组是从零开始的。

运算符[]不执行任何边界检查，这意味着它不会检查索引是否位于0到N-1（包括0和N-1）的范围内。将无效索引传递给运算符[]会导致未定义行为。

数组是少数允许随机访问的容器类型之一，这意味着可以以相同的速度直接访问容器中的每个元素，而不管容器中的元素数量如何。

构造类类型对象时，会优先选择匹配的列表构造函数，而不是其他匹配构造函数。使用不是元素值的初始值设定项构造容器时，请使用直接初始化。

```C++
std::vector v1 { 5 }; // 定义包含一个元素的vector `5`.
std::vector v2 ( 5 ); // 定义包含五个元素的vector，元素被值初始化
```

std::vector可以设置为const，但不能设置为constexpr。

每个标准库容器类都定义了一个名为size_type（有时写为T::size_type）的嵌套typedef成员，它是容器长度（以及索引，如果支持）的类型别名。size_type几乎总是std::size_t的别名，但在极少数情况下可以重写为不同类型。可以合理地假设size_type是std::size_t的别名。

访问容器类的size_type成员时，必须使用容器类的完整模板化名称进行限定。例如，std::vector<int>::size_type。

可以使用size()成员函数查询容器类对象的长度，该函数会以无符号size_type返回长度。在C++17中，还可以使用std::size()非成员函数。

在C++20中，std::ssize()非成员函数会以大型有符号整数类型（通常为std::ptrdiff_t，它通常用作std::size_t的有符号对应类型）返回长度。

使用at()成员函数访问数组元素会执行运行时边界检查（如果越界，则抛出类型为std::out_of_range的异常）。如果未捕获异常，则应用程序会被终止。

运算符[]和at()成员函数都支持使用非常数索引进行获取。然而，两者都希望索引的类型为size_type，这是一个无符号整数类型。当索引为非constexpr时，这会导致符号转换问题。

类型为std::vector的对象可以像其他对象一样传递给函数。这意味着，如果按值传递std::vector，就会生成一个昂贵的副本。因此，通常通过（const）引用传递std::vector，以避免这种复制。

我们可以使用函数模板将任何元素类型的std::vector传递到函数中。可以使用assert()来确保传入的vector具有正确的长度。

术语复制语义是指决定如何制作对象副本的规则。当我们说正在调用复制语义时，意味着已经执行了某些操作来制作对象副本。

当数据所有权从一个对象转移到另一个对象时，我们说数据已经被移动。

移动语义是指决定如何将数据从一个对象移动到另一个对象的规则。当调用移动语义时，会移动任何可以移动的数据成员，并复制任何无法移动的数据成员。移动数据而不是复制数据的能力，可以让移动语义比复制语义更高效，特别是在可以用廉价移动代替昂贵副本时。

通常，当用相同类型的对象初始化对象，或将相同类型的对象赋值给另一个对象时，会使用复制语义（假设没有拷贝省略）。当对象类型支持移动语义，并且用于赋值或初始化的对象是右值时，会自动使用移动语义。

可以按值返回支持移动的类型（如std::vector和std::string）。这样的类型会以较低成本移动其值，而不是制作昂贵副本。

按某种顺序访问容器的每个元素称为遍历容器。

循环通常用于遍历数组，循环变量用作索引。请注意off-by-one错误，也就是循环体少执行或多执行一次。

基于范围的for循环（有时也称为for-each循环）允许遍历容器，而不必显式使用索引。遍历容器时，优先使用for-each。

在基于范围的for循环中使用类型演绎（auto），让编译器推断数组元素类型。每当您通常会通过（const）引用传递该元素类型时，元素声明都应该使用（const）引用。除非需要处理副本，否则可以考虑始终使用const auto&。这将确保即使后来更改了元素类型，也不会发生复制。

非限定作用域枚举可以用作索引，并有助于提供有关索引含义的信息。

每当需要表示数组长度的枚举元素时，添加额外的“count”枚举元素是有用的。可以断言或static_assert数组长度等于计数枚举元素，以确保数组使用了预期数量的初始值设定项进行初始化。

长度必须在实例化点定义、之后不能更改的数组称为固定大小数组或固定长度数组。动态数组（也称为可调整大小的数组）是大小可以在实例化后更改的数组。这种调整大小的能力让std::vector变得特别。

实例化后，可以通过调用resize()成员函数并传入新的所需长度来调整std::vector大小。

在std::vector的上下文中，容量表示std::vector为多少个元素分配了存储空间，长度表示当前正在使用的元素数。可以通过capacity()成员函数查询std::vector的容量。

当std::vector更改其管理的存储量时，这个过程称为重新分配。由于重新分配通常需要复制数组中的每个元素，因此它是一个昂贵过程。所以，我们希望尽可能避免重新分配。

下标运算符（运算符[]）和at()成员函数的有效索引基于vector的长度，而不是容量。

vector有一个名为shrink_to_fit()的成员函数，该函数请求vector收缩其容量以匹配其长度。这个请求没有强制约束力。

元素添加到栈和从栈中删除的顺序可以描述为后进先出（LIFO）。添加到栈上的最后一个元素会最先被移除。在编程中，栈是一种容器数据类型，其中元素的插入和删除以后进先出的方式进行。这通常通过名为push和pop的两个操作实现。

std::vector成员函数push_back()和emplace_back()会增加std::vector的长度，并在容量不足以插入值时导致重新分配。当push触发重新分配时，std::vector通常会分配一些额外容量，以便继续添加其他元素，而不会在下一次添加元素时立刻触发另一次重新分配。

resize()成员函数更改vector的长度和容量。reserve()成员函数仅更改容量。

要增加std::vector中的元素数，请执行以下操作：

1. 通过索引访问vector时使用resize()。这会更改vector长度，以便索引有效。
1. 使用栈操作访问vector时，请使用reserve()。这会在不更改vector长度的情况下增加容量。

push_back()和emplace_back()都会将元素推送到栈上。如果要推送的对象已经存在，则push_back()和emplace_back()是等效的。然而，在创建临时对象并将其推送到vector上的情况下，emplace_back()可能更高效。在创建要添加到容器的新临时对象时，或者在需要访问显式构造函数时，首选emplace_back()。否则，首选push_back()。

std::vector<bool>有一个特殊实现，它会以类似将8个布尔值压缩到一个字节中的方式，更有效地节省布尔值所需空间。

std::vector<bool>并不是真正的vector（它在内存中不需要连续），也不包含bool值（而是包含一组bit），并且不满足C++对容器的定义。尽管在大多数情况下，std::vector<bool>的行为类似于vector，但它与标准库的其余部分并不完全兼容。能与其他元素类型一起使用的代码，可能无法与std::vector<bool>一起使用。因此，通常应避免使用std::vector<bool>。
