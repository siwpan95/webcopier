# 算术转换

> 来源: C++学习网 (studycpp.cn)

---

在前面介绍运算符优先级和结合性时，我们讨论了如何根据表达式中运算符的优先级和结合性来计算表达式。

考虑以下表达式：

```C++
int x { 2 + 3 };
```

```C++
int x { 2 + 3 };
```

```C++
int x { 2 + 3 };
```

| 1 | intx{2+3}; |
| --- | --- |

当调用二元运算符+时，它会接收两个操作数，并且二者都是int类型。由于这两个操作数类型相同，因此计算会使用该类型执行并返回结果。因此，2+3将计算为int值5。

但当二元运算符的操作数是不同类型时会发生什么呢？

```C++
??? y { 2 + 3.5 };
```

```C++
??? y { 2 + 3.5 };
```

```C++
??? y { 2 + 3.5 };
```

| 1 | ???y{2+3.5}; |
| --- | --- |

在这种情况下，操作符+接收一个int类型的操作数和一个double类型的操作数。操作符的结果应该以int、double，还是其他可能的类型返回呢？定义变量时，我们可以选择变量类型。但在其他情况下，例如使用std::cout«时，计算结果的类型会改变输出行为。

在C++中，某些运算符要求其操作数具有相同的类型。如果使用不同类型的操作数调用这些操作符，则会使用一组称为常用算术转换的规则，将其中一个或两个操作数隐式转换为匹配类型。

---

## 需要相同类型操作数的运算符

以下运算符要求其操作数的类型相同：

1. 二元算术运算符：+, -, *, /, %
1. 二元关系运算符：<, >, <=, >=, ==, !=
1. 二进制逐位算术运算符：&, ^, |
1. 条件运算符 ? :（不包括条件表达式，条件表达式应为bool类型）

---

## 常用的算术转换规则

常用算术转换规则有点复杂，因此我们将做一些简化。编译器具有如下所示的类型排名列表：

1. long double（最高级别）
1. double
1. float
1. long long
1. long
1. int（最低级别）

应用以下规则来查找匹配类型：

- 如果一个操作数是整型，另一个是浮点型，则整型操作数转换为浮点操作数的类型（不进行数值提升）。

否则，任何整数操作数都将进行数值提升。

- 如果一个操作数有符号，另一个无符号，则应用特殊规则（见下文）
- 否则，较低级别类型的操作数将转换为较高级别的类型。

> **提示:** 对于高级读者具有不同符号的整数操作数的特殊匹配规则：如果无符号操作数类型的级别大于有符号操作数，则有符号操作数将转换为无符号操作数的类型。如果有符号操作数的类型可以表示无符号操作数类型的所有值，则无符号操作数的类型将转换为有符号操作数的类型。否则，这两个操作数都转换为相应的有符号操作数的无符号类型。

> **提示:** 相关内容您可以在这里找到常用算术转换的完整规则。

## 有符号/无符号的问题

当混合有符号值和无符号值时，这种优先级层次结构和转换规则可能会导致一些问题。例如，查看以下代码：

```C++
#include <iostream>
#include <typeinfo> // for typeid()

int main()
{
    std::cout << typeid(5u-10).name() << ' ' << 5u - 10 << '\n'; // 5u 意味着无符号值 5

    return 0;
}
```

```C++
#include <iostream>
#include <typeinfo> // for typeid()

int main()
{
    std::cout << typeid(5u-10).name() << ' ' << 5u - 10 << '\n'; // 5u 意味着无符号值 5

    return 0;
}
```

```C++
#include <iostream>
#include <typeinfo> // for typeid()

int main()
{
    std::cout << typeid(5u-10).name() << ' ' << 5u - 10 << '\n'; // 5u 意味着无符号值 5

    return 0;
}
```

您可能希望表达式5u-10的计算结果为-5，因为5-10=-5。但实际结果是：

```C++
unsigned int 4294967291
```

```C++
unsigned int 4294967291
```

```C++

```

| 1 | unsignedint4294967291 |
| --- | --- |

由于转换规则，int操作数被转换为无符号int。由于值-5超出了无符号int的范围，因此得到了一个意外的结果。

下面是另一个显示违反直觉的结果的示例：

```C++
#include <iostream>

int main()
{
    std::cout << std::boolalpha << (-3 < 5u) << '\n';

    return 0;
}
```

```C++
#include <iostream>

{
    std::cout << std::boolalpha << (-3 < 5u) << '\n';

    return 0;
}
```

```C++

{

```

| 12345678 | #include<iostream>intmain(){std::cout<<std::boolalpha<<(-3<5u)<<'\n';return0;} |
| --- | --- |

虽然我们很清楚5大于-3，但当这个表达式求值时，-3被转换为大于5的大型无符号整数。因此，上面打印的是false结果，而不是true的预期结果。

这是避免无符号整数的主要原因之一，当您在算术表达式中将它们与有符号整数混合时，您可能会遇到意外结果。编译器甚至可能不会发出警告。
